# Museum React (뮤지엄 리액트 PWA)

## 프로젝트 소개
이 프로젝트는 박물관(Museum) 서비스를 위한 React 기반의 Progressive Web App(PWA) 클라이언트입니다. 기존 HTML/JS 기반의 Museum PWA를 React 생태계로 마이그레이션 및 고도화한 버전입니다.

## 기술 스택 (Tech Stack)
- **Frontend Framework:** React 19
- **Build Tool:** Vite
- **Backend/Hosting:** Firebase
- **Linting:** ESLint

## 시작하기 (Getting Started)

### 설치 (Installation)
```bash
npm install
```

### 로컬 개발 서버 실행 (Development)
```bash
npm run dev
```

### 빌드 (Build)
```bash
npm run build
```

## 배포 (Deployment)
이 프로젝트는 Firebase Hosting을 통해 배포되도록 구성되어 있습니다 (`firebase.json` 참고).
```bash
firebase deploy
```
